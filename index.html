KNN

1. K-Nearest Neighbor (KNN)

ประเภท: Supervised Learning
งานหลัก: Classification
แนวคิด: จุดที่อยู่ใกล้กันมักมี Class ใกล้เคียงกัน
พารามิเตอร์: K = จำนวนเพื่อนบ้านที่ใช้ตัดสินใจ

หลักการทำงาน

Step 1
กำหนด Query Point ที่ต้องการทำนาย
Step 2
คำนวณระยะห่างจาก Query Point ไปยังข้อมูลทุกจุด
Step 3
เลือก K จุดที่มีระยะห่างน้อยที่สุด
Step 4
ใช้ Majority Vote เพื่อหา Class

Euclidean Distance

d = √((x₁ − x₂)² + (y₁ − y₂)²)

ตัวอย่างการคำนวณ

จุด X Y Class
A 1 2 Red
B 2 3 Red
C 3 1 Blue
D 6 5 Blue
Query 2 2 ?

คำนวณระยะจาก Query (2,2):

  • A: √((2−1)²+(2−2)²) = 1.00
  • B: √((2−2)²+(2−3)²) = 1.00
  • C: √((2−3)²+(2−1)²) = 1.41
  • D: √((2−6)²+(2−5)²) = 5.00

กำหนด K = 3 → เพื่อนบ้านที่ใกล้ที่สุดคือ A, B และ C

Voting: Red = 2, Blue = 1
ผลลัพธ์: Query Point ถูกจัดเป็น Class = Red

Visualization: KNN Classification

2. KNN Regression

ประเภท: Supervised Learning
งานหลัก: Regression
ผลลัพธ์: ค่าตัวเลขต่อเนื่อง
ตัวอย่าง: ทำนายราคาบ้าน

หลักการ

KNN Regression มีแนวคิดคล้าย KNN Classification แต่แทนที่จะใช้ Majority Vote จะนำค่าของเพื่อนบ้านมาคำนวณค่าเฉลี่ยเพื่อสร้างค่าทำนาย

ŷ = (y₁ + y₂ + ... + yₖ) / K

สำหรับ Weighted KNN Regression สามารถให้น้ำหนักกับจุดที่อยู่ใกล้มากกว่า เช่น

ŷ = Σ(wᵢyᵢ) / Σwᵢ    โดย    wᵢ = 1 / dᵢ

ตัวอย่าง: House Price Prediction

บ้าน พื้นที่ (m²) ห้องนอน ราคา (พันบาท)
A 80 2 2,000
B 90 2 2,300
C 100 3 2,800
D 130 3 3,500

สมมติบ้านใหม่มีพื้นที่ 95 m² และ 2 ห้องนอน และกำหนด K = 3

หลังจากคำนวณระยะห่างและเลือกเพื่อนบ้าน 3 จุด จะได้ A, B และ C

ŷ = (2000 + 2300 + 2800) / 3 = 2366.67
ผลลัพธ์แบบ Simple KNN Regression:
ราคาบ้านที่ทำนาย ≈ 2,366.67 พันบาท หรือประมาณ 2.37 ล้านบาท

3. K-Means Clustering

ประเภท: Unsupervised Learning
งานหลัก: Clustering
Input: ข้อมูลที่ยังไม่มี Label
Parameter: K = จำนวน Cluster

หลักการทำงาน

Step 1
กำหนดจำนวน Cluster K
Step 2
กำหนดตำแหน่ง Centroid เริ่มต้น
Step 3
คำนวณระยะจากแต่ละจุดไปยัง Centroid
Step 4
Assign จุดไปยัง Cluster ที่ใกล้ที่สุด
Step 5
คำนวณ Centroid ใหม่จากค่าเฉลี่ยของจุดใน Cluster
Step 6
ทำซ้ำจน Centroid และกลุ่มข้อมูลไม่เปลี่ยนหรือเปลี่ยนเพียงเล็กน้อย

Distance

d = √((x − cₓ)² + (y − cᵧ)²)

ตัวอย่างการคำนวณ

กำหนด K = 2 และมีข้อมูลใน Cluster 1 ดังนี้

จุด X Y
P1 1 2
P2 2 3
P3 3 2

Centroid ใหม่คำนวณจากค่าเฉลี่ยของสมาชิกใน Cluster:

Cₓ = (1 + 2 + 3) / 3 = 2
Cᵧ = (2 + 3 + 2) / 3 = 2.33
Centroid ใหม่ของ Cluster 1 = (2, 2.33)

Visualization: K-Means

เปรียบเทียบทั้ง 3 Algorithms

Algorithm Learning Task ผลลัพธ์ แนวคิดสำคัญ
KNN Supervised Classification Class Nearest Neighbors + Voting
KNN Regression Supervised Regression ตัวเลข Nearest Neighbors + Average
K-Means Unsupervised Clustering Cluster Distance + Centroid
ข้อควรจำ: ค่า K มีผลต่อผลลัพธ์ของ KNN และ K-Means ดังนั้นการเลือก K ควรเหมาะสมกับลักษณะของข้อมูลและวัตถุประสงค์ของงาน

สรุป

KNN เป็นอัลกอริทึมที่ใช้ความใกล้ของข้อมูลในการจำแนกประเภท โดยอาศัยการโหวตจาก เพื่อนบ้านที่ใกล้ที่สุด ส่วน KNN Regression ใช้แนวคิดเดียวกันแต่ผลลัพธ์เป็นค่าตัวเลข เช่น ราคาบ้าน สำหรับ K-Means เป็น Unsupervised Learning ที่พยายามแบ่งข้อมูล ออกเป็นกลุ่ม โดยอาศัยระยะห่างระหว่างข้อมูลกับ Centroid และปรับตำแหน่ง Centroid ซ้ำจนได้กลุ่มที่เหมาะสม
